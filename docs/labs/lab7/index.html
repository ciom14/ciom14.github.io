    Лабораторная работа 7

    Тема: Анализ текста

    1. Цель работы

    • Освоить методы предобработки текстовых данных для задач машинного обучения.
    • Изучить принципы векторизации текста с помощью CountVectorizer и TfidfVectorizer.
    • Исследовать влияние различных n-грамм (уни-, би-, три-, пентаграммы) на качество классификации.
    • Изучить роль токенизации, стоп-слов и лемматизации в предобработке текста.
    • Обучить и сравнить несколько моделей машинного обучения для задачи классификации тональности твитов.

    2. Задание

    Построить модель классификации русскоязычных твитов по тональности (positive / negative) с использованием различных методов векторизации текста и сравнить их качество.

    3. Загрузка и подготовка данных

    Датасет состоит из двух CSV-файлов: - positive.csv — твиты с позитивной тональностью - negative.csv — твиты с негативной тональностью Данные объединяются в один датафрейм с меткой класса:

    positive = pd.read_csv('positive.csv', sep=';', usecols=[3], names=['text'])
positive['label'] = ['positive'] * len(positive)

negative = pd.read_csv('negative.csv', sep=';', usecols=[3], names=['text'])
negative['label'] = ['negative'] * len(negative)

df = pd.concat([positive, negative])

    Итоговый датасет разбивается на обучающую и тестовую выборки.

    4. Векторизация текста

    4.1 CountVectorizer

    CountVectorizer преобразует текст в матрицу счётчиков слов. Каждый твит представляется вектором, где каждый элемент — количество вхождений слова в текст.

    Результаты LogisticRegression с CountVectorizer (униграммы):

    precision recall f1-score support
    negative 0.76 0.76 0.76 27848
    positive 0.77 0.77 0.77 28861
    accuracy 0.77 56709
    macro avg 0.77 0.77 0.77 56709
    weighted avg 0.77 0.77 0.77 56709

    4.2 TF-IDF

    TfidfVectorizer учитывает не только частоту слова в документе, но и его редкость по всему корпусу. Слова, встречающиеся во всех текстах (например, стоп-слова), получают меньший вес.

    Сравнение TF-IDF с различными n-граммами:

    n-грамм accuracy f1 negative f1 positive
    Униграммы (1,1) 0.76 0.75 0.77
    Биграммы (2,2) 0.71 0.69 0.72
    Триграммы (3,3) 0.71 0.69 0.72
    Пентаграммы (5,5) 0.56 0.19 0.70

    Вывод по n-граммам: лучший результат показывают униграммы. Чем длиннее n-грамма, тем реже она встречается в тестовых данных — растёт разреженность матрицы, и модель хуже обобщается. Пентаграммы (5,5) дают наихудший результат: модель почти всё предсказывает как positive (recall=0.99, precision=0.54), так как почти не встречает знакомых 5-словных комбинаций в тесте.

    5. Токенизация и стоп-слова

    Стандартный CountVectorizer разбивает текст по пробелам. Более качественная токенизация через word_tokenize (NLTK) корректно отделяет пунктуацию от слов.

    Удаление стоп-слов (часто встречающихся слов без смысловой нагрузки: «и», «в», «на» и т.д.) позволяет сосредоточиться на значимых признаках.

    smart_tokenizer = CountVectorizer(ngram_range=(1,1), tokenizer=word_tokenize, stop_words=stopwords)

    6. Важность пунктуации

    При сохранении пунктуации (analyzer='char' или без удаления стоп-слов) метрики классификатора резко возрастают до ~1.0.

    Причина: датасет был размечен именно по смайликам

    Это означает, что один символьный паттерн является идеальным предиктором, и модель фактически «читерит», найдя этот маркер. Данный эффект демонстрирует важность эксплоративного анализа данных перед построением модели.

    7. Лемматизация (pymorphy3)

    MorphAnalyzer из библиотеки pymorphy3 приводит слова к начальной форме (лемме): «бегу», «бежал», «бежит» → «бежать».

    from pymorphy3 import MorphAnalyzer
pymorphy3_analyzer = MorphAnalyzer()

    Лемматизация уменьшает словарь и помогает модели лучше обобщаться, объединяя разные формы одного слова в один признак.

    8. Сравнение классификаторов

    В качестве базового метода использована LogisticRegression. Дополнительно протестированы XGBClassifier и MultinomialNB на векторизации с smart_tokenizer.

    Классификатор accuracy f1 negative f1 positive
    LogisticRegression 0.77 0.76 0.77
    XGBClassifier 0.74 0.74 0.73
    MultinomialNB 0.78 0.77 0.78

    MultinomialNB показал наилучший результат.

    9. Выводы

    В ходе лабораторной работы была решена задача классификации русскоязычных твитов по тональности. Исследованы различные подходы к векторизации и предобработке текста.

    Основные результаты:

    • Лучший результат среди классификаторов показал MultinomialNB — accuracy 0.78. что объясняется его эффективностью на разреженных матрицах счётчиков слов.
    • Пунктуация является ключевым признаком датасета — её сохранение даёт accuracy ~1.0, поскольку смайлики использовались как критерий разметки.
    • Длинные n-граммы (биграммы, триграммы, пентаграммы) ухудшают качество на коротких текстах из-за разреженности данных.
    • Токенизация и удаление стоп-слов незначительно улучшают результат по сравнению с базовым CountVectorizer.
    • Лемматизация позволяет сократить словарь и улучшить обобщение модели.
